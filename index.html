Encapsulamiento, modificadores de acceso

Qué es el encapsulamiento?

Es proteger los datos de una clase para que nadie los pueda cambiar directamente desde afuera por equivocación. Se oculta la información y solo se permite modificar mediante reglas o métodos específicos.

Ejemplo de Encapsulamiento:

public class CuentaBancaria
{
    // El saldo está oculto y protegido
    private decimal saldo;

    // Método para cambiar el saldo de forma segura
    public void Depositar(decimal monto)
    {
        if (monto > 0)
        {
            saldo += monto;
        }
    }
}

Modificadores de acceso

Son palabras clave que definen quién tiene permiso de ver o usar una variable o método:

  • public: Todo el mundo puede verlo y usarlo sin restricciones.
  • private: Es un secreto. Solo se puede usar dentro de la misma clase donde se creó.
  • protected: Es familiar. Lo puede usar la clase original y las clases hijas que hereden de ella.
  • internal: Es local del proyecto. Solo se puede ver dentro del mismo proyecto actual.

Ejemplos de los modificadore

1. public:

public class Juego
{
    public string NombreNivel = "Nivel 1"; // Visible desde cualquier lugar
}

2. private:

public class Persona
{
    private int contrasena = 1234; // Solo visible dentro de Persona
}

3. protected:

public class Animal
{
    protected void Respirar() { } // Visible en Animal y sus clases hijas
}

4. internal:

public class ConexionBD
{
    internal string Servidor = "192.168.1.1"; // Visible solo en este proyecto
}
